## 夹爪控制

### 功能描述

夹爪（J4，PA2）由手柄肩键控制：LB 打开，RB 闭合。夹爪逻辑独立在 `GripperController` 中，与大小臂联动分开，避免两者相互影响。

### 方案选型与原因

- **独立模块**：夹爪目标由 `gripper.h` / `gripper.cpp` 维护，主程序只调用 `gripper.update()` 和 `gripper.target()`。原因：夹爪参数经历多次迭代，单独封装后改参数不会影响大小臂逻辑。
- **步进方式：每 20ms 最多移动 1°**。原因：舵机直接跳到目标会产生冲击，逐步移动更平稳；松开按键后保持当前目标，不回弹。
- **限位：硬限 70..110°，并用 `static_assert` 检查常量关系**。原因：参数改动时，编译期即可发现起始角超出范围这类错误（见第二阶段）。
- **同时按下：目标保持不变**（代码行为，尚未实物测试）。

### 迭代过程

#### 第一阶段：张开过大

- **问题**：早期夹爪开合正常，但全开张角过大，接近机械边缘。
- **尝试**：把全开上限逐步收窄。
- **结论**：这一阶段只确认了张角过大，并未形成稳定的最终参数。

#### 第二阶段：LB 无效（限幅冲突）

- **问题**：参数迭代中出现过 `72..88°` 的版本，用户反馈"LB 完全不动"。
- **尝试**：检查逻辑后发现，起始角 `J4_START = 90` 高于上限 `J4_MAX = 88`，第一步就被限幅钳到 88，之后无法再增加。
- **失败原因**：起始值超出了设定范围，违反了参数的隐含约束。
- **定位与修正**：此后用 `static_assert` 在编译期检查关系。版本历史为 `65..115`、`70..98`、`72..88`、`75..94`，每次迭代都是为了解决上一版的实测问题。
- **结论**：起始角必须位于开合目标之间，并在编译期检查。

#### 第三阶段：最终参数

| 参数 | 数值 |
|---|---|
| 硬限 | 70° ~ 110° |
| 起始 | 90° |
| 闭合目标（RB） | 75° |
| 打开目标（LB） | 105° |
| 步进 | 1° / 20ms |

- **状态**：参数已写入固件，编译和烧录通过。
- **未验证**：105° 是否为真实机械安全端点，75° 是否能夹住目标物，尚无实物动作记录。

### 当前状态与遗留问题
