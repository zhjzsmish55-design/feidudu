## 底盘转向（J1）

### 功能描述

J1 是底盘转向舵机，接在 PA0，由右摇杆 X 控制，角度范围 70..110°，中立 90°。左摇杆 Y 仍负责整车前进和后退，左摇杆 X 不参与转向。

本功能只针对 `usb_cdc_control` 固件（方案 A）。比赛底盘采用方案 B（`ps2_control`），它没有转向舵机，见 [07 底盘运动（PS2 麦克纳姆）](07-底盘运动-PS2麦克纳姆.md)。

### 方案选型与原因

- **早期方案：PB10 作为"底座"**，由十字键左右控制，角度范围 35..145°。
- **中期方案：左摇杆 X 控制 PA0 转向**。
- **当前方案：右摇杆 X 控制 PA0**，左摇杆 X 不再控制转向，左摇杆 Y 仍为油门。
- **为什么改为右摇杆**：用户选择右摇杆 X 控制转向，左摇杆保留给整车移动，使两个摇杆分别负责"走"和"转"，操作上不冲突。

### 问题与修正

早期 J1 的定义与实物不符：用户实际需要的是底盘转向舵机，而代码中 J1 被当作底座使用（PB10）。这一错误在前期开发中留了下来。

修正步骤：

1. 确认用户需求：J1 应为底盘转向，由右摇杆 X 控制。
2. 固件中取消 PB10 底座控制，J1 映射到 PA0。
3. 桥接程序读取右摇杆 X（代码中为 Axis 2），换算为 `70..110` 的转向角度：`S = 90 + x × 20`。
4. 左摇杆 X 不再用于转向。
