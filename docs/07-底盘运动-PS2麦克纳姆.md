## 底盘运动（PS2 麦克纳姆）

### 功能描述

`ps2_control` 是一套四轮麦克纳姆底盘的控制代码，用 PS2 手柄通过接收器控制四个轮子，实现前后、左右平移以及斜向移动。它对应手册中"底盘运动"指标，要求用 PS2 手柄控制底盘。

本套代码是比赛采用的底盘控制方案。它与 [04 底盘转向（J1）](04-底盘转向.md) 中的 `usb_cdc_control` 固件不是同一套代码，没有转向舵机，也没有 J1。

### 方案选型与原因

- **PS2 手柄 + 接收器**：手册要求底盘运动使用 PS2 手柄控制。接收器安装在机器人上，手柄与机器人之间通过无线连接，不经过电脑。
- **四轮麦克纳姆（X 型布置）**：可以实现平移和斜向移动，不需要转向舵机。
- **DRV8833 电机驱动**：两块，每块驱动两个电机通道。
- **继电器（PA10）**：控制电机供电的通断，手柄断开或急停时切断动力。手册要求的无线断电继电器已购买，尚未装机。

### 控制逻辑

- 左摇杆 Y：前进和后退。
- 左摇杆 X：左右平移。
- 两者叠加：斜向移动。
- 不支持原地旋转。

麦克纳姆轮混合公式（X 型布置）：

```text
LF = throttle + strafe
RF = throttle - strafe
LR = throttle - strafe
RR = throttle + strafe
```

油门和平移量会按比例缩放，使斜向运动保持方向比例；峰值限制为 `THROTTLE_LIMIT = 120`（约为满 PWM 的 47%）。

每个轮子的方向可以通过 `MOTOR_LF_SIGN`、`MOTOR_RF_SIGN`、`MOTOR_LR_SIGN`、`MOTOR_RR_SIGN` 修正，混合公式保持不变。

### 安全机制

- 上电后输出全部停止，继电器断开。
- 必须先收到有效的、回中的模拟帧，底盘才会解锁。
- 数字模式帧不含摇杆数据，底盘保持停止，直到手柄回到模拟模式（`0x73` 或 `0x79`）。
- 无效帧或超过 250ms 无有效帧时，停止电机并清除解锁状态；恢复需要摇杆重新回中。
- SELECT 键切换急停，急停状态在摇杆回中前保持锁存。
- 无效 PS2 帧不会复用旧的驱动命令。
