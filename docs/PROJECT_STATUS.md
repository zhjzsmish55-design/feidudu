## 系统概述

仓库中有两套控制代码：

- **方案 A：`usb_cdc_control`（机械臂 + 转向舵机）**。Xbox 手柄经电脑端桥接程序（`xbox_control_bridge.py`），通过 USB CDC 虚拟串口把控制帧发给 STM32F103C8T6（Blue Pill）。Blue Pill 驱动 4 个 SG90 舵机（J1 转向、J2 大臂、J3 小臂、J4 夹爪）和两路电机通道。测试阶段使用 Xbox 手柄。
- **方案 B：`ps2_control`（四轮麦克纳姆底盘）**。PS2 手柄经接收器直接与 Blue Pill 通信，驱动 4 个轮子，无转向舵机。**这是比赛采用的底盘方案**，见 [07 底盘运动（PS2 麦克纳姆）](07-底盘运动-PS2麦克纳姆.md)。

## 串口协议（方案 A）

桥接程序发送的控制帧（换行结尾，ASCII）：

```
S:<70..110>,T:<-255..255>,J2:<-1|0|1>,J3:<-1|0|1>,LB:<0|1>,RB:<0|1>\n
```

| 字段 | 含义 |
|---|---|
| S | 底盘转向角度（由右摇杆 X 换算，`90 + x × 20`） |
| T | 油门（由左摇杆 Y 换算，死区 0.08） |
| J2 | 大臂方向（十字键左 -1 / 右 +1） |
| J3 | 小臂方向（十字键下 -1 / 上 +1，方向待实物确认） |
| LB / RB | 夹爪打开 / 闭合 |

固件回传 `ACK:S:<角度>,T:<油门>,ARM:<0|1>,J:<J1>,<J2>,<J3>,<J4>`，状态变化时回传，最多每 100ms 一次。
